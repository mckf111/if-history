# 如果历史：刻下无名

一款从小人物开始的历史叙事游戏。你扮演北京城破后的虚构女刻工姚小满：她没有兵，也没有圣旨，只有一把刻刀。三回合里，她会改变一个人的身份、一船粮的去向与一座营门的开合。

历史不会被一个神奇错字拯救。你能改变的是证据如何被发现、复制、相信和出卖，再由时代里的其他人把这点偏差继续放大。

## 怎么玩

每回合都按同一个节奏推进：

1. 读完现场与人物对话，弄清每个人想保住什么。
2. 在右侧“先看清”中检查至少两件物品。
3. 选择一个行动。每个行动都要求你看过对应证据；人物关系也可能封死一条路。
4. 查看即时后果、人物反应和新欠下的债。
5. 让后果进入下一回，最终查看完整的“选择 → 传播 → 相信 → 历史行动”因果链。

三个选项都有人付出代价，没有标准答案。首局约 15 分钟；最重要的不是猜作者心思，而是记住：你在决定谁先付账。

## 运行与验证

需要 Node.js 20.19–20.x，或 Node.js 22.12 及更高版本。

```powershell
npm install
npm run dev
```

浏览器通常会打开 `http://localhost:5173`。生产验证命令：

```powershell
npm test
npm run build
npm run preview
```

游戏是纯前端应用，没有运行时大模型、联网接口、账号或付费功能。事件、人物和结局均为随构建发布的本地内容，存档只保存在当前浏览器中。

## 当前实现

```text
src/
├── main.tsx                 # 当前应用入口
├── story/
│   ├── StoryApp.tsx         # 新版页面与交互
│   ├── content.ts           # 三回合人物、场景、选择与后果
│   ├── engine.ts            # 纯函数叙事状态机与存档校验
│   ├── storage.ts           # v3 本地存档
│   ├── types.ts             # StoryState 与内容接口
│   └── *.test.ts            # 叙事引擎与存档测试
└── game/                    # 旧版十二回合策略引擎及测试
```

当前入口使用 `src/story/`，存档键为 `what-if-history.story.v3`。旧版《煤山未尽》保留在 `src/game/`，其 `what-if-history.autosave.v2` 存档不会被新版覆盖，但旧版目前没有从界面进入的入口。

实现细节见 [架构说明](docs/ARCHITECTURE.md)，史实与架空的分界见 [史实边界与资料](docs/HISTORICAL-NOTES.md)。

## 设计原则

- 人物不是立场标签：每个人都有欲望、能力、恐惧和可以背叛自己的理由。
- 文书不是魔法：证据必须经过船主、营兵、军属和守门人，才可能变成行动。
- 选择不是善恶题：每个行动都救下一些东西，也制造一笔会回来索债的账。
- 历史与架空分开写：史实提供时代约束，虚构人物和后果明确标为推演。
