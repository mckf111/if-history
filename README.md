# 如果历史：煤山未尽

一款单人、纯前端的明末策略叙事游戏。玩家扮演没有在煤山自缢的崇祯，在有限信息、有限资源和失灵的国家机器中走完十二回合，尝试让南迁后的朝廷活过 1645 年。

这不是历史知识问答，也不是“选正确答案”的分支小说。每道旨意都会改变财政、军队、民生、法统和朝局；需要人物执行的命令还会在后续回合按照当时条件进行可复现判定。

## 运行

需要 Node.js 22 或更高版本。

```powershell
npm install
npm run dev
```

终端会显示本地地址，通常为 `http://localhost:5173`。若端口已占用，Vite 会自动顺延。

生产构建与测试：

```powershell
npm test
npm run build
npm run preview
```

## 首版内容

- 三幕十二回合，每回合处理一份主线奏案和一份局势奏案。
- 12 个主线事件、15 个动态事件，每局经历其中 12 个动态事件。
- 8 名可委任人物、5 项隐藏国势、2 类明确资源和延迟 1–2 回合的执行结果。
- 6 类主要国运结局，并按百姓、制度和北方关系生成长期尾声。
- 单自动存档、最近 20 卷结局记录、固定种子复盘和桌面/手机布局。
- 史实边界与来源可在每份奏案中展开查看。

推荐使用桌面浏览器完成首局，预计 20–40 分钟。手机可以完整游玩，但舆图与国势会排在奏案之后。

## 游戏规则

国本、饷道、兵权、民生、朝局在界面中只显示“崩坏、动摇、可支、稳固、振兴”，精确数值只在结局公开。内帑和驿骑是可计数资源。

需要执行者的政策会显示定性风险。实际胜算由事件难度、当前国势、执行者能力和其与皇帝的关系共同决定，并限制在 10%–90%。随机状态写入存档，所以刷新或重复读取不会改变已经确定的历史。

游戏没有运行时大模型、联网接口、账号或付费功能。所有事件和尾声均为人工编写的本地内容。

## 项目结构

```text
src/
├── App.tsx                 # 首页、奏案、舆图、结局与交互
├── styles.css              # 残卷舆图视觉与响应式布局
└── game/
    ├── engine.ts           # 纯函数状态机、掷判和结局
    ├── mainEvents.ts       # 十二个必经事件
    ├── dynamicEvents.ts    # 每幕局势事件池
    ├── people.ts           # 人物能力与初始关系
    ├── sources.ts          # 史料索引
    ├── storage.ts          # 本地存档与甲申史鉴
    └── *.test.ts           # 引擎与存档测试
```

实现细节见 [架构说明](docs/ARCHITECTURE.md)，历史取舍见 [史实边界与资料](docs/HISTORICAL-NOTES.md)。

## 版本控制

- `main` 始终保持测试和生产构建通过。
- 首个可玩版本使用 `v0.1.0` 标签。
- `dist/`、`node_modules/`、Playwright 临时产物和 TypeScript 构建缓存不进入 Git。
