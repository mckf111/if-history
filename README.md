# 城破前夜：刻下无名

![《城破前夜：刻下无名》封面：金色月轮、北京外城木刻剪影与朱红印章](public/og-cover.png)

## [点这里，马上开始游戏](https://mckf111.github.io/if-history/)

不用安装，不用注册，也不用付钱。打开网页就能玩。

一局大约需要 **20～40 分钟**。游戏会自动存档，中途关掉网页，下次还能接着玩。

> 这是一款历史推演游戏。故事会提到战争、死亡和处决，但没有血腥画面。

## 这是一个什么故事？

时间是 1644 年，北京城快要失守了。

你扮演年轻刻工 **姚小满**。她没有军队，也不是大官，只有一把刻刀和制作文书的本事。

北京城一定会失守，这件事改不了。但你也许能改变三件小一些、却和普通人性命有关的事：

- 城门打开时，附近的街坊能不能少受一些伤害；
- 匠人的名册会不会落到抓人的人手里；
- 小满的弟弟春生能不能平安坐船离开。

你要先弄清每个人害怕什么、想要什么，再制作文书，把消息送到合适的人手里。一张纸不会自动创造奇迹，真正改变事情的是读到它、相信它并采取行动的人。

## 第一次玩，照着这 6 步走

### 1. 先选一件最想保护的事

点击 **“立下一局的誓”**，然后在“人、册、门”里选择一个目标。

这个选择不会偷偷给你加分。到了结局，游戏会告诉你当初的愿望有没有实现。

### 2. 到城里走一走

点击右边城图上的地点，就能过去。**走路不花时辰**，可以放心多看看。

不会使用鼠标时，可以按 `Tab` 找到地点，再按 `Enter` 或空格前往。

### 3. 先看，再问

- 点击 **“细看”**：检查眼前的物品；
- 点击 **“探问”**：向在场的人打听消息。

细看和探问都会花掉一个时辰，但它们会告诉你东西藏在哪里、人物每天去哪里，以及他们最在意什么。

### 4. 找到制作文书需要的东西

纸、印章和笔迹样本散落在不同地点。有些可以买，有些需要先观察或打听才能取得。

回到刻字铺，点击 **“上工作台”**。工作台会直接告诉你每种文书还缺什么，不需要自己猜。

### 5. 制作文书，再找人送出去

在工作台里：

1. 选择文书的样子；
2. 选择要写的一两句话；
3. 决定花一个还是两个时辰制作。

做好后，点击 **“托人送出”**。带信的人也有自己的心思：有人会认真送到，有人会改话、转卖，甚至把信藏起来。

### 6. 夜里看消息，三天后看结局

每天用完四个时辰，就会进入夜晚。夜报只告诉你街上听得到的动静，不会直接告诉你每个人心里在想什么。

到了三月十九日，游戏会公开：

- 你最初的愿望有没有实现；
- 门、名册和春生的命运为什么改变，或者为什么没有改变；
- 每一步选择是怎样传到结局的；
- 事实、当时的记载和百年后的传说有什么不同。

游戏有 **七类正常结局**，还有一种被抓后的失败结局。失败也会留下属于这一局的故事。

## 屏幕上的词是什么意思？

| 看到的词 | 大白话解释 |
| --- | --- |
| 时辰 | 每天可以做四次费时间的事。走路和当面托信不费时辰。 |
| 嫌疑 | 别人觉得你可疑的程度。到 4 会被盘问，到 7 可能被搜查，到 10 会被抓。 |
| 袖中 | 你现在带着的纸、印、笔迹样本和文书。 |
| 人物册 | 你亲自打听到的人物信息和行踪。没打听过的事不会提前告诉你。 |
| 史鉴 | 玩过几局后留下的收藏册，记录发现过的结局、人物和因果。 |
| 种子 | 这一局的随机编号。同一个编号加上同样的选择，会得到同样的结果。 |

## 卡住了怎么办？

- **东西拿不了**：先点击附近的“细看”，或者向相关人物“探问”。
- **工作台什么都做不了**：点开一种文书，看清“还缺”后面写的东西，再去城里找。
- **没有人愿意带信**：找赵四、豆子或吴七娘。他们要正好在你身边，才能接过文书。
- **嫌疑太高**：回刻字铺，选择“等一时辰”，躲在阁楼里才会降低嫌疑。
- **不知道信该送给谁**：先想一想，这句话最能打动谁的愿望，或者最能吓到谁。
- **时间快用完了**：已经做好的文书要尽快送出去。留在袖子里的纸不会改变任何人。

最重要的一条：**没有碰过的事情，不会靠运气自动成功。**

## 存档、联网和隐私

- 游戏会自动保存当前一局；
- 开新局前会先提醒，不会悄悄覆盖旧档；
- 不需要账号，没有广告、内购或付费内容；
- 没有运行时人工智能，也不会把选择和存档上传到服务器；
- 存档只保存在当前浏览器中。清除浏览器数据后，存档也会消失。

## 想在自己的电脑上运行

不会写代码、只想玩游戏的人，可以跳过这一节，直接使用上面的在线地址。

开发运行需要 Node.js 20.19～20.x，或 Node.js 22.12 及更高版本。

```powershell
npm install
npm run dev
```

浏览器通常会自动打开 `http://localhost:5173`。

提交改动前，请运行：

```powershell
npm test
npm run build
npm run audit:public
```

这三条命令分别检查游戏规则、生产构建，以及公开页面的标题、说明、分享图、站点地图和权利声明。

## 史实与架空边界

本作只把居庸关失守、崇祯十七年三月十八日日晡外城陷、十九日昧爽内城陷及帝崩万岁山作为不可改动的史实骨架。

姚小满与其余人物、六处游戏地点、具体文书、街巷行动、三个局部撬点及全部偏转结局，均为虚构或架空推演，不宣称为真实人物和真实事件。游戏内的史实陈述提供来源；架空内容明确标注为“架空推演”，不为虚构情节伪造史料。
