## 配图 1 · 夜刻氛围（插图1）

- **位置**：冷开场之后、「游戏叫…」之前（或紧接游戏名段落后）
- **目的**：把「二十鞭」的紧张感落到具体劳动场景
- **Type / Style / Aspect**：scene / woodcut-editorial / 16:9

```
做一张横版编辑插画（16:9），用于中文公众号正文。

主题：城破前夜，刻字铺里的普通劳动。

深夜晚明小型木版刻字铺。一名虚构的年轻中国女刻工（靛青粗布、实用发髻、无首饰）在油灯下俯身刻版；前景可见刻刀、木纹、磨损木戳、一叠粗纸、一捆暗示亲人牵挂的小布包。窗外是城墙剪影与黎明前冷雾。一根极细朱红绳从布包绕过木戳，止于她执刀的手——表示因果牵连，不是法术。

情绪：安静里的紧迫，普通人的劳作，没有英雄光环。

风格：晚明木刻版画融合当代高级编辑插画；粗糙墨线、旧宣纸纹理、轻微套印错位；木炭黑、旧纸米色、烟灰蓝、少量朱红。

画面内不要任何文字、数字、水印、Logo、可读书法。不要真实历史人物肖像，不要血腥，不要战场，不要宫殿，不要现代物件。

Clean composition with generous breathing room. Human figures: stylized illustration, not photorealistic.
Aspect ratio: 16:9
```

**Alt**：夜色刻字铺，女刻工在油灯下制版

## 配图 2 · 门册人三目标（插图2）

- **位置**：「门 / 册 / 人」表格附近（表前或表后，勿与表重复堆叠）
- **目的**：3 秒看懂本局争什么
- **Type / Style / Aspect**：infographic / editorial / 16:9

```
做一张横版信息图（16:9），编辑设计风，干净留白。

主题：游戏三个局部目标，不是国运总分。

ZONES：
- 顶部一行小标题
- 中部三列等宽卡片
- 底部一行极短注释

LABELS（必须原样使用中文，勿增删）：
- 小标题：你争的不是江山
- 左卡标题：门
- 左卡正文：城门打开时，街坊少受伤害
- 中卡标题：册
- 中卡正文：匠人名册会不会完整落入征发者手
- 右卡标题：人
- 右卡正文：运夫少年能否坐船离开
- 底注：城破本身改不了 · 局部命运仍可争

视觉：每卡一个极简图标——门缝暖光、名册卷轴、红绳与小船剪影。无写实人脸，无血腥，无皇帝龙椅。三卡之间可用极细朱红线暗示彼此牵连。

COLORS（仅渲染指导，不要把色号画进图里）：
- 背景 #F7F1E8
- 卡片 #FFFFFF
- 墨线 #2A2A2A
- 强调朱红 #A83228
- 暖纸 #E8D5B5

STYLE：editorial print，细线，轻阴影，像杂志内页图解。
Clean composition with generous white space.
Color values and names are rendering guidance only — do NOT display hex codes or color names as visible text.
Aspect ratio: 16:9
```

**Alt**：三列图解：门、册、人三个局部目标

## 配图 3 · 纸 → 相信 → 行动（插图3）

- **位置**：「你动的是纸，承受结果的是人」段落后
- **目的**：讲清“文书 ≠ 权力”
- **Type / Style / Aspect**：framework / scientific-editorial / 4:3

```
做一张 4:3 概念框架图，科学编辑风，冷静清楚。

主题：文书不自动产生授权——它只推动信念，人物自己行动。

三层横向台阶或漏斗（从上到下）：
1) 文书到达
2) 有人相信
3) 人物按欲望与恐惧行动

LABELS（原样中文）：
- 标题：纸改变的是相信
- 层1：送达 · 带信人可能照送 / 加戏 / 转卖 / 昧下
- 层2：验看 · 精明、成色、想信程度共同起作用
- 层3：行动 · 欲望与恐惧决定他做什么
- 侧注：命令 ≠ 结果

视觉：信封/纸页图标 → 半透明“信念”条 → 小人剪影迈步；可用朱红细绳串联三层。不要天平正义女神，不要现代手机界面。

COLORS（勿显示色号）：
- 背景 #F8F6F1
- 层块 #E7EEF5 / #F3E6D8 / #F0D9D4
- 文字墨色 #222222
- 强调 #8C2F28

STYLE：scientific editorial，线性图标，留白大。
Human figures: simplified stylized silhouettes only.
Color values are rendering guidance only — do NOT paint hex codes as text.
Aspect ratio: 4:3
```

**Alt**：三层框架：送达、相信、人物行动

## 配图 4 · 史实骨架 vs 架空推演（插图4）

- **位置**：「三层编年史」与「它现在是什么」之间
- **目的**：建立信任，降低「乱改历史」误解
- **Type / Style / Aspect**：comparison / mono-ink editorial / 16:9

```
做一张左右对比图（16:9），单色墨线编辑风，克制可信。

左栏标题：史实骨架（不可改）
右栏标题：架空推演（可玩）

LABELS（原样中文）：
- 总标题：哪些钉死，哪些可争
- 左1：居庸关不守
- 左2：三月十八日外城陷
- 左3：三月十九日内城陷
- 左4：帝崩万岁山
- 右1：姚小满与刻字铺
- 右2：具体文书与断言
- 右3：门 / 册 / 人局部撬点
- 右4：人物欲望、恐惧与结局分叉
- 底注：史实给来源 · 架空标边界

视觉：左栏沉稳深灰石碑感色块，右栏浅纸色可写空间；中间一条朱红细线分界。不要把真实历史人物画成肖像。

COLORS（勿显示色号）：
- 左 #2B2F36 文字浅
- 右 #F3EBDD 文字深
- 分界线朱红 #A83228 细线

STYLE：mono-ink + editorial，像博物馆说明牌。
Clean, high trust, no drama blood.
Color values are rendering guidance only — do NOT display them as text.
Aspect ratio: 16:9
```

**Alt**：对比图：不可改的史实骨架 vs 可玩的架空推演

## 统一禁忌（所有生图）

- 不画真实历史人物可辨认肖像
- 不血腥、不酷刑、不色情
- 不出现假官网、假二维码、假价格、「重磅上线」贴纸
- 中文标签控制在短词级，避免整段正文贴进图
- 朱红细绳 = 因果路径，不是魔法
