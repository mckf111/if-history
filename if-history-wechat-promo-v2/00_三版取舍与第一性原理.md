# 三版取舍与第一性原理

## 目标

一周阅读破 1000。不改仓库、不政治、不脏词、不引导消费。

## 第一性：一篇游戏推广文真正要完成什么

公众号冷启动不是「写全产品说明书」，而是完成四件事：

1. **3 秒停住**：标题/首屏制造认知冲突（城破改不了 × 小人物仍可争）
2. **30 秒信**：用可核验细节证明「真有这游戏、真好玩、真不骗人」
3. **3 分钟懂**：只讲一个差异点——纸改变的是相信，不是国运
4. **一次行动**：点阅读原文开一局；留言同时给低门槛问题（门/册/人）

其余全部是噪音。

## 本版策略（取长补短）

**保留 Grok**

- 文虎写作底色：拆解者姿态、禁用词清扫、边界前置、不教育读者
- 中文封面/插图 prompt 的可操作性（维度表 + 独立代码块）
- 发布包文件结构清晰

**吸收 Claude**

- 冷开场：测评局「二十鞭」+ 可回放的因果总账
- 题眼按钮：同种子重走 · 骰子不变
- 互动设计：低门槛选门/册/人 + 试玩后贴结局摘要
- 标题矩阵与首周外部导流

**吸收 GPT**

- 正式入口 `https://if-history.caowenhu.com/`、版本 v0.6.0
- 木刻编辑风 + 朱红细绳因果线的视觉连续性
- 结局克制写法：不把「出城」吹成团圆
- 游戏原句核对：「你动的是纸，承受结果的是人」
- 涌现叙事的事实边界：事件节点可预写，组合与因果链由规则接成

**砍掉**

- 过长的「适合谁/不适合谁」清单
- AGPL / 仅 GitHub Pages /「公开源码」等过时或不可访问表述
- 「没有预写剧本」「仓库里搜不到」「不是编剧写的」等无条件夸张
- 「送信耗时」等与代码不符的玩法说明
- 套话与消费暗示

## 本版文章主线（一句话）

> 一封写得太好的假信，让弟弟挨了二十鞭——事件节点写在规则里，这一局的完整因果链由玩家操作与人物信念接成；城破改不了，你能动的只有门、册、人。
