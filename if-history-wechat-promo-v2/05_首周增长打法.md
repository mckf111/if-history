# 首周阅读破 1000：执行清单

> 目标是有效触达，不是标题党透支信任。阅读破 1000 是检查点，不是保证。禁止刷量、诱导分享、无关群发。

## 发布前 30 分钟

- [ ] 作者过一遍「交给作者的清单」（见 `06_质检报告.md`）
- [ ] 用 `02` 生成封面 → `cover-hero` + `cover-share-1x1`
- [ ] 用 `03` 至少生成插图 1+2（截图 S1–S3 已就位）
- [ ] 微信内置浏览器实测：阅读原文能否打开 `https://if-history.caowenhu.com/`
- [ ] 正文首屏已标明这是《城破前夜》游戏故事（见主标题「游戏里」）
- [ ] 摘要与置顶同时含低门槛问题（门/册/人）与试玩后摘要邀请
- [ ] 正文未附无法访问的 GitHub「源码」链接

**建议发布时间**：周四 21:00–21:30（备选：周三同时段 / 周五 20:30）。以你号的历史打开率为准。

## Day 1～2

- 次日 7:30 朋友圈二次：换备选标题做转发语，不重复首发长文
- 根据留言把卡关点补进置顶（如「文书缺材料先细看」）
- 有长评且对方同意，可截「读者说」发短动态，链回正文

## Day 3～4

半周复盘短内容（朋友圈即可）：

> 目前最多人卡在：要件没收齐 / 没人带信。记住：先细看再回铺子；做好的文书别捂在袖子里。托信本身不耗时，真正吃时辰的是看、问和刻。

把人带回游戏，不另开长文也行。

## Day 5～7 外部导流（破千保险丝）

公众号正文外链受限。外部平台发「内容摘要 + 公众号名」，引导搜索「能文能虎」，或贴文章二维码。

| 平台 | 动作 | 要点 |
| --- | --- | --- |
| 知乎 | 答「免费网页游戏 / 历史题材游戏」类问题 | 改写素材，勿整篇搬运；署公众号名 |
| 即刻 | 3 图（封面+主界面+结局）+200 字 | 强调因果链可追溯、同种子可复盘、规则组合产生不同后果 |
| 小红书 | 方图封面 + 口语正文 | 评论区答玩法；标签：独立游戏/历史/网页游戏 |
| V2EX | 分享创造节点，工作日上午 | 技术向：纯函数、种子、重放校验；勿假装仓库已公开 |
| B 站动态 | 低成本 | 金句卡或结局截图 + 搜公众号 |

每个平台 24 小时内有问必答。

## 阶段检查点（不是 KPI 考核）

| 时间 | 健康信号 | 若偏弱 |
| --- | --- | --- |
| 24h | 有真实留言讨论门/册/人 | 加强种子用户私聊 + 钩子转发语 |
| 72h | 出现「我玩完了」类反馈 | 发半周卡关提示，导回游戏 |
| 7d | 阅读接近或过 1000 | 外部平台补一波设计向短帖 |

## 明确不做

- 不刷阅读、不买量、不互点联盟
- 不写「限时免费」「今天不玩就亏」类消费暗示
- 不碰现实政治站队、敏感影射
- 不为了推文去改 if-history 仓库或强行发版
- 不把「事件节点预写 + 规则组合」吹成「机器凭空写作」
