# 封面图提示词

**操作**：复制下方主推 prompt → 粘贴进 ChatGPT → 模型选 **gpt-image-2** → 导出公众号头图；再中心裁切一张 1:1 作分享方图。

**推荐维度**

| 维度 | 取值 | 理由 |
| --- | --- | --- |
| Type | scene + metaphor | 夜刻场景承载情绪，朱红细绳点出因果 |
| Palette | dark + warm accent | 墨黑 / 旧纸米色 / 烟灰蓝 / 少量朱红 |
| Rendering | woodcut-editorial digital | 晚明木刻 × 当代编辑插画（GPT 视觉语言） |
| Text | title-only | 标题短、好认；或 none 后在后台叠字 |
| Mood | balanced → 略偏 bold | 有点击欲，不血腥 |
| Aspect | 2.35:1（头图）/ 1:1（分享） | 见各条末尾 |
| Font | serif | 历史题材，衬线更稳 |

**封面标题文字（写死，与主标题一致）**：
`一封假信，二十鞭`

若后台用备选主标题「我做了一个救不了明朝的游戏」，改用备选 Prompt 的标题行。

## 主推 Prompt（夜刻 · 红绳分叉 · 2.35:1）

```
做一张微信公众号封面图，画幅 2.35:1 横版宽幅。

视觉类型：场景 + 隐喻（scene + metaphor）。深夜晚明小型刻字铺内景。画面中心安全区（中央约 45%）是：一名虚构的年轻中国女刻工（普通百姓装束，深蓝靛青粗布短袄，发髻实用，无首饰），在一盏低矮油灯下俯身刻木版，姿态专注而疲惫，不是英雄亮相。桌上有未装订的粗纸、一方磨损木戳、几块字版。透过窄窗，远景是黎明前灰蓝的城门剪影与模糊的普通人影。一根克制的朱红细绳从刻刀起，经过纸页，向三个方向分叉：城门缝、一页名册、一个极小的人形剪影——表示「门 / 册 / 人」三条因果，不要画成魔法光线。

风格：晚明木刻版画与当代高级编辑插画的融合；粗糙墨线、旧宣纸纹理、轻微套印错位感。配色仅作渲染指导：木炭黑、旧纸米色、烟灰蓝、少量朱红。整体克制、有重量、可触摸，不要卡通可爱，不要高饱和。

人物：风格化插画，不要写实摄影脸，不要可辨认的真实历史人物。

标题文字必须原样出现（中文）：
一封假信，二十鞭
字体：典雅衬线，大号，高对比，放在右侧或右上留白区，不要遮挡刻刀、油灯与红绳分叉点。不要出现其它多余文字、水印、Logo、网址、英文乱码、数字角标。

禁忌：无血腥、无酷刑、无战场群像、无龙袍皇冠、无宫殿主场、无法术光效、无现代物件、无旗帜标识。

构图干净，留白充足，手机缩小后仍能看清主体与标题。
Aspect ratio: 2.35:1
```

## 备选 Prompt A（无字头图 · 后台自叠标题）

```
做一张微信公众号封面图，画幅 2.35:1，画面内完全不要任何文字。

深夜晚明刻字铺。虚构年轻女刻工在油灯下刻版；桌上纸、木戳、字版；窗外城门剪影。一根朱红细绳从刻刀分向城门、名册、小人剪影。晚明木刻 × 当代编辑插画，墨黑 / 旧纸米色 / 烟灰蓝 / 少量朱红。无血腥，无真实历史人物肖像，无现代物件，无水印。中央 45% 为安全区，便于裁成 1:1。
Aspect ratio: 2.35:1
```

## 备选 Prompt B（极简三印 · 品牌感）

```
做一张微信公众号封面图，画幅 2.35:1。

视觉类型：极简概念（minimal）。米白宣纸质感背景上，横向排列三枚风格化方印（不是真实官印复制）：印文分别为「门」「册」「人」，印色朱红；「人」印下拖出一根极细红绳。背景几乎空白，只有极淡夜色渐变。

标题文字必须原样出现：
我做了一个救不了明朝的游戏
黑色衬线，放在三印上方，字距舒适。不要其它文字。

风格：flat-vector 混合轻微纸纹，像当代编辑设计封面，冷静可信，不可爱。
Aspect ratio: 2.35:1
```

## 导出建议

| 用途 | 比例 | 文件名建议 |
| --- | --- | --- |
| 公众号头条封面 | 2.35:1，宽 900+ px | `cover-hero.jpg` |
| 分享缩略 / 次条 | 1:1 中心裁 | `cover-share-1x1.jpg` |
| 朋友圈单图 | 保持标题可读 | `cover-moments.jpg` |

生成后检查：中文标题无缺笔乱码；无血腥；无真实历史人物肖像；红绳不像霓虹魔法。
