## 四、P0 必改项

### P0-1：纠正「没有预写剧本」的过度表述

当前问题：

- `01_文章正文.md` 写着「没有任何一段预写剧本写着‘弟弟翻墙挨鞭’」。
- `00`、`04`、`05` 和 `README` 也反复使用「搜不到预写剧本」「不是编剧写的」「系统自己长出来」等口径。

但当前代码中确实存在作者预写的事件内容：

- `src/sim/content/npcActions.ts` 中有「翻营墙被抓」「挨了二十鞭」的行动文本。
- `src/sim/engine/humanFates.ts` 中有「春生此前翻营失败、挨了二十鞭」的命运文本。

因此，不能再声称仓库里没有这段事件，也不能暗示系统在运行时现场生成了这段剧情文字。

升级后必须准确表达下面这层意思：

> 「二十鞭」的事件节点和文字由作者预先写入规则；这一次游戏里，从假信、相信、行动到受罚的完整因果链，不是线性剧本按固定顺序播放，而是由玩家操作、人物信念、概率判定和 NPC 行动规则共同接成。

允许使用「规则组合」「因果链」「非线性触发」「这一局把它们接在了一起」等说法。

全文禁止继续使用以下无条件表述：

- 没有预写剧本
- 仓库里搜不到
- 不是编剧写的
- 系统自己写出了剧情
- 游戏现场生成了这个故事

如果使用「涌现叙事」，必须紧跟一句大白话解释，说明涌现的是**事件之间的组合与因果链**，不是机器凭空写作。

### P0-2：纠正「送信消耗时辰」

当前 `01_文章正文.md` 写着：

> 观察、探问、制书、送信，才会让倒计时往前走。

这与当前实现不一致。`src/sim/engine/actions.ts` 中 `dispatch` 返回零时辰，代码注释为「托信是一句话的事；真正的成本在刻和部件上」。相关测试也确认送信不推进时辰。

升级后的玩法说明必须满足：

- 走路不耗时。
- 送信不耗时。
- 观察、探问和制书会推进倒计时。
- 不要为了句子整齐而补写未经代码证实的资源规则。

全文检索，确保没有其他段落暗示「送信会推进倒计时」。

### P0-3：纠正私有仓库与公开资产记录

当前问题：

- `01_文章正文.md` 文末把 `https://github.com/mckf111/if-history` 标成公开「源码」。
- 正文又写「仓库里留了公开的资产记录」。
- 推广包 `README.md` 也列出了同一源码链接。

当前仓库为私有仓库，普通读者访问该 GitHub 地址会得到 404。`docs/DEPLOY-EDGEONE.md` 也明确说明，EdgeOne 发布的是构建产物，不会让私有 GitHub 仓库自动公开。

执行要求：

- 从玩家可见正文和推广包入口中移除「公开源码」链接。
- 不再声称读者可以进入仓库核验资产记录。
- 可以诚实说明开发过程使用了 AI，但不要附带当前无法公开验证的承诺。
- 不得为了满足旧文案而擅自公开仓库或上传一份临时源码镜像。

## 五、P1 传播微调

### P1-1：让读者第一眼知道这是游戏中的故事

主标题的冲突力很强，应保留「假信／二十鞭」这组核心意象。但标题、封面副标题、摘要三者中，至少有一处必须明确出现「游戏里」或《城破前夜》，避免读者把它误认成真实历史轶事。

不要把标题改成泛泛的「我做了一款历史游戏」。冲突仍然要在前，游戏身份负责消除误读。

### P1-2：降低开头的信息拥堵

开头应保留：

- 春生相信假信。
- 翻墙失败，挨了二十鞭。
- 这是一次真实测评局的结果。
- 回看记录能找到完整因果链。

概率、骰值和人物检测可以保留作为可信证据，但不要让多个名字、四个数字和三层机制同时挤在首屏。读者应先看懂「发生了什么」，再看「系统怎样算出来」。

不得虚构玩家评论、媒体评价、上线数据或作者没有亲自经历过的感受。

### P1-3：减少中段的产品说明书感

现稿中段的表格、分隔线、功能说明和合规信息较密，阅读体验接近发布说明。升级时：

- 保留「门、册、人」的清楚选择。
- 保留「轻信不是因为蠢，是因为想要」。
- 保留「你动的是纸，承受结果的是人」。
- 保留同种子重走、骰子不变的解释。
- 保留游戏体量和边界，不包装成开放世界或无限内容。
- 把隐私、AI、授权等不同话题拆开表达，不要全塞进一个长段落。

不要为了追求所谓公众号长度强行扩写。当前篇幅已经适合推广，升级后以紧凑、能一口气读完为优先。

### P1-4：降低留言门槛

当前 CTA 要求读者完整试玩后，再把故事压成一句话发到评论区，参与成本偏高。

升级后应同时提供一个不试玩也能回答的低门槛问题，例如让读者在「门、册、人」中选一个最想保住的对象。试玩后的结局摘要可以作为第二层邀请，而不是唯一的留言任务。

不得使用抽奖、限时、付费、打赏或制造焦虑的方式换取互动。

### P1-5：统一访问入口

正式游玩入口统一为：

`https://if-history.caowenhu.com/`

正文不要反复堆放裸链接。根据公众号实际能力，在正文、二维码或「阅读原文」中选一个主入口，发布前亲自确认可以打开。GitHub Pages 只能作为回退，不得重新写成官方主入口。
