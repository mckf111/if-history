# 原创性、授权与可追溯边界

## 能做到什么，不能承诺什么

公开发布的网页无法从技术上保证“绝不被复制”。本项目也主动采用开源与知识共享授权：符合条款的复制、修改与非商业再创作本来就是被允许的。真正可执行的目标是：不侵犯他人权利；让原创形成过程可核对；让他人必须署名、按相同协议分享，并为违规商业使用保留追责证据。

## 本项目的原创面

- 姚小满与其余虚构人物、人物关系、六处游戏地点、文书组合、九根信念支柱、三个撬点、八类结局及三层编年史，均由本项目独立创作。
- 首页与分享图中的月轮、城墙、坊巷和印章均由仓库内的 SVG/CSS 代码绘制，不包含第三方图片、商标、角色造型或商业游戏素材。
- 三张章节木刻图由图像生成工具按本项目提示词生成，不使用第三方图库素材；生成源与处理记录见 [生成图像资产记录](ART-ASSET-PROVENANCE.md)。
- 游戏不使用第三方音乐、音效或字体文件；声音由浏览器本地实时合成，字体只调用玩家操作系统已有字体。
- 《明史》《甲申传信录》《大明会典》等古籍仅作为公有领域史料；游戏逐条区分史实背景、史料争议与架空推演，不把古籍原文据为原创。

## 版本与权利证据

1. Git 提交保存每次设计、规则、文本与视觉变更的作者时间线；发布版本使用语义化版本号。
2. 页面元数据、`public/rights.txt`、仓库许可证与页脚使用一致的版权人和授权口径。
3. 代码按 AGPL-3.0-only 授权；叙事与视觉内容按 CC BY-NC-SA 4.0 授权；版权人保留另行商业授权的权利。
4. 搜索抓取与模型训练分开声明：允许搜索索引与用户主动访问，不授权 GPTBot 训练。抓取声明不替代许可证，也不能约束不遵守 robots.txt 的第三方。
5. 商务入口、商标保留与待补证据分别见 [商务合作](../BUSINESS.md)、[商标说明](../TRADEMARKS.md) 和 [权利资料室清单](RIGHTS-DATA-ROOM-CHECKLIST.md)；未完成的原始素材归档、身份确认与正式商标检索不会被写成已经完成。

## 新增素材的准入规则

- 只提交自己创作、明确购买授权或确认属于公有领域的素材。
- 每个外部素材必须在同一提交中记录作者、原始链接、许可证、取得日期与允许的使用方式；信息不全则不合入。
- 不以“风格像某位在世艺术家”作为视觉生产要求，不复刻在售游戏的界面、角色、标志或宣传构图。
- 新增史实陈述要给可访问来源；新增架空内容必须明写为“架空推演”。
