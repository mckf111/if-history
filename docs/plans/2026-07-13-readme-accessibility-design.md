# README 易读性重写设计

## 目标

让第一次接触游戏的儿童、老年人和非技术用户，只读 README 前半部分就能知道游戏讲什么、如何开始、每个按钮做什么，以及卡住时如何继续。

## 采用的结构

1. 在线游玩入口放在标题和封面之后，不让安装说明挡住普通玩家。
2. 用六个按键步骤解释完整一局，不先讲状态机、传播模型和概率公式。
3. 用“大白话解释”表格翻译时辰、嫌疑、袖中、人物册、史鉴和种子。
4. 单独提供“卡住了怎么办”，回答工作台缺件、无法采集、找不到带信人和嫌疑过高等实际问题。
5. 本地运行与开发文档放到玩家说明之后，并链接到现有深入文档，避免 README 再复制整套架构。

## 不做通俗化改写的部分

史实与架空边界、原创形成记录、复制与抓取声明、双轨许可证适用范围及版权人信息继续使用准确、正式的书面表达。通俗不能以削弱法律或史料边界为代价。

## 验收条件

- 不懂“随机种子”“信念传播”或“状态机”的读者，也能按顺序走完第一局。
- README 中的按钮名称与 v0.3 实际界面一致。
- 版本号、测试命令、存档版本、史实日期、许可证和版权人信息与仓库当前状态一致。
- Markdown 链接、公开发布审计、测试与生产构建全部通过。
