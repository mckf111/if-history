# 游戏内新手引导设计

## Goal

让完全没有读过 README 的玩家，只靠游戏内界面就能回答四个问题：我是谁、这一局要达成什么、界面上的主要区域与数值有什么用、现在具体应该先做哪一步。玩家选择誓愿后，应能在一分钟内完成第一次有目的的移动或调查，而不是靠试点按钮猜规则。

## Assumptions and Boundaries

- 这次解决的是首次体验断层，不修改人物模拟、胜负结算、随机模型或内容表。
- 誓愿仍然只决定终局追问，不提供暗中加成；引导必须如实说明这一点。
- 不增加存档字段，不升级存档版本。首次自动打开玩法册只根据现有命令记录判断。
- 第二局及中途续玩不能被强制教学打断，但玩法说明必须始终能从主游戏页重新打开。
- 保留现有“夜色、案卷、朱印”的视觉语言，不引入与叙事氛围冲突的发光箭头或游戏化任务清单。
- 工作区已有大量未提交改动；本次只触碰直接服务新手引导的文件。

## First-principles diagnosis

玩家进入复杂系统时，首先需要的不是完整规则，而是连续的认知闭环：先知道目标，再看懂可用手段，然后得到一个明确的当前行动，最后从系统反馈中确认自己理解正确。当前首页已解释题材，序章已要求选择誓愿，主游戏页也有一句动态提示；缺口在于三者没有连成一条线。玩家选完誓愿后直接面对时间、嫌疑、银两、地图、人物、物件、袖中和工作台，必须自己从密集信息中反推玩法。

因此不采用单独堆一篇说明，也不采用锁死操作的逐按钮教学。前者仍把理解责任交给玩家，后者会破坏自由推演并让后续局显得拖沓。采用四层、同一套口径的游戏内引导：序章明确本局目标；第一次进入主游戏页自动打开一张简短玩法册；主游戏页常驻显示誓愿和当前下一步；顶栏提供可随时重开玩法册的入口。

## Experience design

1. 首页主按钮直接写“开始游戏”，副文案说明先选一个要保住的人或事，避免把文学化按钮名称当成唯一操作提示。
2. 序章在三张誓愿卡之前明确说明：城破不可阻止；本局目标是让所选的人或事在三天后的真实结算中被保住；誓愿不是加成。
3. 玩家落印后，首次自动打开“先看懂这一局”玩法册。玩法册只讲三件事：目标、行动循环、界面词义，并给出与当前誓愿对应的第一步。
4. 关闭玩法册后，主界面顶部保留“本局要守住 / 现在先做”任务条。下一步由现有 `SimState` 纯推导，不写入状态、不改变合法命令。
5. 初始阶段在视觉上强调真正相关的区域：还没到目标地点时强调外城图；到达后强调人物或物件区域。提示不替玩家执行命令，也不限制其他合法行动。
6. 顶栏加入“玩法”按钮。无论玩家何时忘记时辰、嫌疑、袖中或工作台的含义，都能在当前页面重新打开说明。

## Components and data flow

- 新增纯展示模块保存誓愿标题、首步文案与动态下一步推导。输入只有 `SimState`，输出只有玩家可见文本和当前应强调的界面区域。
- 新增玩法册组件，复用现有 `Modal`，不直接修改状态。关闭玩法册只改变 `PlayScreen` 的局部界面状态。
- `PlayScreen` 继续只通过 `dispatch(PlayerCommand)` 提交游戏动作。引导不会直接写 `SimState`。
- 首次自动打开条件为：当前命令序列只有一条 `choose-vow`。刷新一个尚未采取行动的新局会再次打开；已经行动或续玩的存档不会被打断。

## Success Criteria

- 首页按钮明确表达“开始游戏”。
- 序章在游戏内说明不可改变的历史目标与本局可追求的局部目标。
- 选择任意誓愿后，玩法册自动出现，并同时解释目标、循环、时辰、嫌疑、银两、外城图、袖中、人物册和工作台。
- 关闭玩法册后，主界面持续显示所选誓愿和一个可立即执行的下一步。
- 三种誓愿的第一步都指向开局真实可到达、有人或物可调查的地点。
- 玩法册可从主界面重新打开；中途续玩不会自动弹出。
- 不新增存档字段，不改变规则层，不使用随机数。
- 新增引导测试通过，`npm test` 与 `npm run build` 通过；1440×900 和 390×844 视口无溢出、遮挡或不可操作项。

## Verification for Each Step

1. 纯函数测试三种誓愿的首步、移动后的首步和关键进度阶段。
2. 静态渲染测试验证序章、玩法册和主游戏入口包含必要信息。
3. 全量测试确认规则、存档和随机重放没有回归。
4. 生产构建确认类型、资源路径和样式打包正常。
5. 真实浏览器从首页依次走过开始、选誓、玩法册、关闭、首步移动，并分别检查桌面与手机视口。

## Final Completion Criteria

一个没看 README 的新玩家打开游戏后，不需要猜“我该干什么”：他能在游戏里读到本局目标，理解主要界面词义，获得与自己誓愿一致的第一步，并且之后随时找回玩法说明。所有这些改动只发生在展示层，原有模拟与存档保持不变。
